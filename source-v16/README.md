# Golos 0.16

Изменения относительно 0.15:

- исправлен порядок завершения обучения кодовой фразе, из-за которого кнопки могли оставаться заблокированными после сохранённого примера;
- чтение AudioRecord во время обучения переведено в READ_NON_BLOCKING с обработкой отрицательных кодов и прерывания;
- добавлена пользовательская команда выключения ночного режима;
- стандартная команда «Ночь стоп» сохраняется по умолчанию;
- команды «сохранить», «сохрани», «отмена» и «отменить» нельзя использовать как команду выключения;
- диагностика тестирует выбранную пользователем команду;
- добавлены unit-тесты пользовательской команды выключения;
- versionCode 16 / versionName 0.16.
